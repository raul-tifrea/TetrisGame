# Simple Tetris

A classic Tetris game implementation in Java using Swing.

## Requirements

- Java Development Kit (JDK) 8 or higher.

## How to Run

1. Compile the Java source files or import the project into an IDE like IntelliJ IDEA or Eclipse.
2. Run the `main.Main` class to start the game.

## Controls

- **Up Arrow**: Rotate the block
- **Down Arrow**: Move the block down faster
- **Left Arrow**: Move the block left
- **Right Arrow**: Move the block right
- **Spacebar**: Pause / Resume the game

## Project Structure

- `src/main`: Contains the core game logic, main loop, rendering, and input handling.
- `src/tetrisobj`: Contains the definitions for the different Tetris block shapes.
